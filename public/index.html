The architecture

A single GridRoom Durable Object owns the state and exposes three RPC methods: snapshot, toggle, setPixels. Three interfaces converge on them.

  1. UI click → POST /api/toggle → room.toggle(x, y)
  2. HTTP API → POST /api/set-matrix → room.setPixels(...)
  3. MCP tool call → GridMCP agent → room.setPixels(...)

Every mutation broadcasts a diff over a hibernatable WebSocket (/ws) to every connected browser. The MCP tool is literally a caller of the same RPC — there is no "MCP subsystem".

HTTP API

curl -X POST http://localhost:8787/api/set-matrix \
  -H 'content-type: application/json' \
  -d '{"pixels":[[10,10,1],[11,10,1],[12,10,1]]}'

MCP endpoint

Streamable HTTP at /mcp, served by McpAgent from Cloudflare's agents package, which wraps the official @modelcontextprotocol/sdk McpServer. Point Claude Desktop, MCP Inspector, or any MCP client at it. 

npx @modelcontextprotocol/inspector http://localhost:8787/mcp
