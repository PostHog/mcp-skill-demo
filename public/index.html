MCP Surface

grid://current resource

The current grid as 32 lines of 32 characters. 0 = white, 1 = black. Format matches the bits argument of write, so a row can be sliced and passed straight back.

clear tool

Set every pixel to white. No parameters.

write tool

Write a run of pixels starting at a linear address. Wraps across rows.

offset int Linear address 0–1023. Row-major: y * 32 + x
bits string One char per cell. 1 = black, 0 = white, . = skip

Architecture

A single GridRoom Durable Object owns the pixel state. Every interface — browser, HTTP, MCP — calls the same RPC methods on it. Mutations broadcast diffs over a hibernatable WebSocket to all connected browsers.

UI click → POST /api/toggle → room.toggle(x, y)
HTTP API → POST /api/set-matrix → room.setPixels(...)
MCP tool → GridMCP agent → room.writeBits(...)

HTTP API

curl -X POST ORIGIN/api/set-matrix \
  -H 'content-type: application/json' \
  -d '{"pixels":[[10,10,1],[11,10,1],[12,10,1]]}'
